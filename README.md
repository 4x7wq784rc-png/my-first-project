# ✨ まほうのシールちょきん（ごほうびシールアプリ）

ディズニーが大好きなお子さん向けの、**おてつだい・ごはん完食・歯みがき**などをがんばると
シールが貯まり、貯まると「ディズニーでアイス」などのごほうびがもらえる、こども向けごほうびアプリです。

実物のシール帳と同じ体験を、スマホ・タブレットでも楽しめます。

## できること

- 🌟 **おやくそく（タスク）をタップ** → シールがもらえる（キラキラ演出＆効果音）
- 🏰 **ごほうびまでの進み具合** をバーとシール帳で見える化
- 🎉 シールが目標数たまると **お祝い演出**（紙吹雪・ファンファーレ）→「ごほうびをもらう！」
- ⚙️ **おうちの人せってい**：ごほうび名・必要なシール数・タスクを自由に追加／削除
- 🔒 **おうちの人パスコード**：4けたのパスコードを設定すると、設定画面を開くときに
  ロックがかかり、お子さんが勝手に設定変更できなくなります（くうらん＝ロックなし）。
  わすれた場合は「パスコードをわすれたとき」からデータをリセットして解除できます。
- 📖 **これまでのきろく**：もらったごほうび回数・あつめたシール・がんばりの履歴
- 🔄 タスクは **毎日リセット**（日付が変わるとまた挑戦できる）
- 💾 データは端末内（localStorage）に保存。ネットがなくても動きます

## つかいかた

1. `index.html` をスマホ／タブレット／PC のブラウザで開くだけ。
2. （アプリっぽく使いたい場合）ブラウザの共有メニューから
   **「ホーム画面に追加」** すると、アイコンから起動できる PWA になります。
3. 最初に右下の **⚙️ おうちの人せってい** から、ごほうび名・シールの目標数・
   おやくそくリストをお子さんに合わせて調整してください。

### ホスティングして使う場合（任意）

PWA のオフライン機能（Service Worker）を完全に有効にするには HTTPS 配信が必要です。
GitHub Pages などに公開するか、ローカルで簡易サーバを立てて開いてください。

```sh
# 例：このフォルダで簡易サーバを起動
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS すべて入り、これ単体で動作） |
| `manifest.webmanifest` | PWA 設定（ホーム画面追加用） |
| `sw.js` | オフライン用 Service Worker |
| `icon.svg` | アプリアイコン |
