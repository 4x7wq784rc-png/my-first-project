# 23区 賃貸併用ウォッチ

東京23区の売り土地・新築戸建・中古戸建・収益物件を、主要サイトから毎朝集めて、
賃貸併用住宅（融資2億円程度）に向く物件だけを一覧にします。

## 使い方
```
python3 -m bukken.run                 # 全サイト取得 → 判定 → report/ に一覧を出力
python3 -m bukken.run --sites suumo   # 一部のサイトだけ
```
- 条件の変更: `bukken/config.py`（予算・土地面積・駅徒歩・キーワード）
- 判定のしくみ: `bukken/evaluate.py`
- 前日までに見た物件: `data/seen.json`（これと比べて「新着」を決めます）

## 判定
- 土地: 1億2,000万円以下・60㎡以上・駅徒歩15分以内・建てられる延床（土地×容積率）120㎡以上。
  延床150㎡以上かつ徒歩10分以内でA、建築条件付きは減点。
- 建物付き: 2億円以下。「賃貸併用・二世帯・店舗付」などの言葉がある、または収益物件ならA/B、
  延床150㎡以上ならB（改装・建替えの余地）。

## 対象サイト
取得: SUUMO, Yahoo!不動産, 三井のリハウス, 東急リバブル, ノムコム, 三井住友トラスト不動産,
住友不動産販売, 三菱UFJ不動産販売, センチュリー21, オウチーノ, 不動産投資連合隊（収益物件）。
robots.txt を守り、同じサイトへは3秒以上あけて取得します。
自動取得を拒否・確認画面を出すサイト（HOME'S, at home, 不動産ジャパン, ハトマーク, 楽待,
健美家, みずほ不動産販売, ピタットハウス, goo住宅・不動産, 東京建物不動産販売）は使っていません。
