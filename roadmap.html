0. 前提と全体像

100億円の意味を分解する

「年商100億円」は、達成経路によって難易度も必要なリソースも大きく変わります。まず構造を分解します。

売上100億円 = 顧客数 × 顧客単価 × 購入頻度
モデル 顧客単価の目安 必要顧客数の目安 代表的な業態
高単価・少数 1億円 100社 大型BtoB / SaaSエンプラ / 製造
中単価・中数 100万円 1万社 中堅BtoB / 業務SaaS
低単価・多数 1万円 100万人 BtoC / EC / アプリ

重要: どの掛け算で100億円に到達するのかを最初に決める。これがビジネスモデルの背骨になる。

時間軸（標準シナリオ：7〜10年）

  • Phase 1（0〜1年）: 創業・PMF前 — 売上0〜1億円
  • Phase 2（1〜3年）: PMF達成・初期成長 — 売上1〜10億円
  • Phase 3（3〜6年）: スケール — 売上10〜50億円
  • Phase 4（6〜10年）: 市場リーダー化 — 売上50〜100億円超

Phase 1 — 創業とPMF前（0〜1年 / 売上 0〜1億円）

ゴール

  • 「誰の・どんな課題を・どう解決するか」を1文で言える状態
  • 課金してくれる最初の顧客（10〜30社 or 数百人）の獲得
  • ユニットエコノミクスの初期検証

やること

  1. 法人設立
    • 株式会社の設立（資本金・株主構成・定款）
    • 創業者間契約（株式の分配、ベスティング、競業避止）
    • 会計・税務の体制（クラウド会計 + 税理士契約）
  2. 課題とソリューションの検証
    • 顧客インタビュー 30〜50件
    • MVP（最小機能製品）の構築と提供
    • 価格仮説の検証（払う意思があるか）
  3. 創業チーム組成
    • 事業・開発・営業のコア3〜5名
    • 役割と意思決定ルールの明確化

この段階のKPI

  • 有料顧客数 / 解約率 / NPS / 受注リードタイム
  • バーンレートとランウェイ（資金が尽きるまでの月数）

資金

  • 自己資金 + エンジェル / シード（数千万〜1億円規模）

Phase 2 — PMF達成と初期成長（1〜3年 / 売上 1〜10億円）

ゴール

  • PMF（プロダクトマーケットフィット）の確認
  • 再現性のある獲得チャネルを1〜2本確立
  • 黒字化、もしくは明確な黒字化パスの提示

PMFの判断基準（例）

  • 解約率が十分に低い（BtoB SaaSなら月次1%前後以下）
  • オーガニック / 紹介経由の流入が増えている
  • 「これがなくなったら困る」と言う顧客が4割超（Sean Ellisテスト）

やること

  1. 獲得チャネルの確立
    • インバウンド（SEO / コンテンツ / 広告）
    • アウトバウンド（インサイドセールス / フィールドセールス）
    • パートナー / 代理店
  2. 組織化
    • The Model型（マーケ → IS → FS → CS）の導入
    • 採用の仕組み化（20〜50名規模へ）
  3. ユニットエコノミクスの健全化
    • LTV / CAC > 3
    • CAC回収期間 < 12ヶ月

資金

  • シリーズA（数億〜十数億円）
  • 成長投資（人材・マーケ・プロダクト）

Phase 3 — スケール（3〜6年 / 売上 10〜50億円）

ゴール

  • 「再現可能な成長エンジン」を回し、前年比1.5〜2倍成長を継続
  • 複数チャネル / 複数プロダクトでの成長

やること

  1. Go-To-Marketの拡大
    • 営業組織の大型化と分業の深化
    • エンタープライズ攻略（大型契約・アップセル）
    • 新規セグメント / 新規地域への展開
  2. プロダクトの多角化
    • 既存顧客への追加プロダクト（クロスセル）
    • プラットフォーム化 / API / エコシステム
  3. オペレーショナルエクセレンス
    • データ基盤・KPIダッシュボードの整備
    • ユニットエコノミクスの継続改善
    • SLA / 品質 / セキュリティ（ISO27001, SOC2 等）
  4. 組織と経営
    • 経営チーム（CxO）の補強
    • ミドルマネジメント層の育成
    • 100〜300名規模の組織設計と企業文化の維持

資金

  • シリーズB / C（数十億円）
  • M&Aによる非連続成長の検討

Phase 4 — 市場リーダー化（6〜10年 / 売上 50〜100億円超）

ゴール

  • 対象市場でのトップ3シェア
  • 安定した収益基盤と次の成長の柱

やること

  1. 非連続成長
    • M&A / 事業買収による売上・顧客基盤の獲得
    • 海外展開
    • 新規事業（第2・第3の柱）
  2. ガバナンスと上場準備
    • 内部統制（J-SOX相当）
    • 監査法人 / 主幹事証券の選定
    • IPO or 戦略的売却（M&A Exit）の意思決定
  3. ブランドと人材
    • 採用ブランドの確立（500名超規模）
    • 経営の自走化（創業者依存からの脱却）

横断テーマ（全フェーズ共通）

ファイナンス戦略

Phase 資金調達 目的
1 エンジェル / シード 検証・MVP
2 シリーズA チャネル確立・黒字化
3 シリーズB/C スケール・人材
4 レイター / IPO 市場リーダー化・Exit

主要KPIツリー

売上 (ARR/年商)
├── 新規売上
│   ├── リード数 → 商談数 → 受注数（各転換率）
│   └── 平均単価（ACV）
└── 既存売上
    ├── 継続率（NRR：ネットレベニューリテンション）
    └── アップセル / クロスセル
  • North Star: NRR > 120%（既存顧客だけで成長する状態）

組織・人材

  • 採用は「カルチャーフィット × スキル」の両軸
  • 各フェーズで必要な人材タイプは変わる（0→1人材 / 1→10人材 / 10→100人材）
  • 経営陣の役割分担とアカウンタビリティの明確化

リスク管理

  • 資金枯渇（ランウェイ管理を最優先）
  • キーパーソン依存
  • 法務 / コンプライアンス / 情報セキュリティ
  • 市場・競合・規制の変化

最初の90日でやること（アクションリスト）

  • 100億円到達モデル（単価 × 顧客数 × 頻度）を1枚にまとめる
  • 解決する課題と対象顧客を1文で定義する
  • 顧客インタビューを30件実施する
  • MVPの仕様を決め、最小スコープで構築する
  • 最初の有料顧客を獲得する
  • 法人設立・創業者間契約・会計体制を整える
  • 主要KPIと計測手段を決める
  • 12ヶ月の資金計画（バーン / ランウェイ）を作る

補足：100億円企業の「型」の例

  1. SaaS型: 月額課金 × 高NRR × 低解約。再現性が高く投資家評価も高い。
  2. マーケットプレイス型: 需給を仲介し手数料を取る。ネットワーク効果が堀になる。
  3. D2C / EC型: ブランド × LTV最大化。在庫・物流の運用力が鍵。
  4. エンタープライズBtoB型: 大型契約少数。営業力と導入支援が競争力。
  5. ロールアップ型: M&Aで同業を統合し規模を作る。資本効率と統合力が要。

どの型を選ぶかで、必要な能力・資金・時間軸が決まる。自社の強みと市場機会の交点を選ぶこと。

このロードマップはテンプレートです。事業内容が具体化したら、各フェーズの数値目標・KPI・資金計画を実数で埋めて運用してください。
